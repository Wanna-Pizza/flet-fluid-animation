# flet-fluid-animation

## NOT FINISHED, NEED SOME WORK 

FletFluidAnimation control for Flet

## Installation

Add dependency to `pyproject.toml` of your Flet app:

* **Git dependency**

Link to git repository:

```
dependencies = [
  "flet-fluid-animation @ git+https://github.com/MyGithubAccount/flet-fluid-animation",
  "flet>=0.27.6",
]
```

* **PyPi dependency**  

If the package is published on pypi.org:

```
dependencies = [
  "flet-fluid-animation",
  "flet>=0.27.6",
]
```

Build your app:
```
flet build macos -v
```
